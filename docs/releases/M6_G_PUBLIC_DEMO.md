# M6-G Public Demo Release

## Summary

This public release presents the frozen M6-G real-NX milestone as a concise technical showcase. It preserves the existing public repository history and does not transfer the private engineering implementation.

## Demonstrated result

The fixed Goal is: Create a 100 × 50 × 20 mm block. The milestone summary reports real NX 2512 execution, Block feature creation, and independent geometry verification.

[Watch the M6-G demo](../../demo/M6-G-demo.mp4) · [Architecture](../architecture/M6_G_ARCHITECTURE.md) · [Showcase](../showcase/M6_G_SHOWCASE.md)

## Public package

- README and high-level architecture
- M6-G showcase and release notes
- A short sanitized MP4 and thumbnail
- Public-facing example request

No runnable private implementation, NX part file, raw evidence, or real execution log is included.

## Validation scope

The M6-G milestone is frozen. The public statement is limited to the capabilities listed above; this release does not claim a general-purpose CAD system or universal NX-version compatibility.

## Limitations

- One bounded Block workflow is demonstrated.
- A live run requires a local NX2512 environment and the private runtime.
- M7 Multi-Skill Agent and M8 Developer Platform remain roadmap items.
