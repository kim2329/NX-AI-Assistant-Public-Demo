# Demo Flow

The included recording demonstrates one Create Block workflow in Siemens NX 2512.

1. The user enters: “create a block 50x50x100mm”.
2. The assistant identifies the intent as **Create Block**.
3. The assistant selects **CreateBlockSkill** and presents editable dimensions.
4. The request is confirmed and executed in the connected NX session.
5. A block appears in the NX modeling view and the assistant reports completion.

The recorded dimensions are 50 mm × 50 mm × 100 mm. The recording demonstrates this specific prototype workflow; it does not establish support for arbitrary natural-language modeling requests.
